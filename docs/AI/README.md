# StatGate Sovereign AI Governance & Traceability

## Principles
1. **Grounded In Institutional Context**: AI investigations and queries are grounded in verified Knowledge Graph records and canonical objects from the Knowledge Fabric.
2. **Deterministic Auditing**: Every AI generation, recommendation, feedback action, and query is logged to `platform_audit_log` with actor, tenant, and correlation ID context.
3. **No Phantom Citations**: AI findings must link back to authoritative source IDs and versions in the Data Catalogue or Knowledge Base.
