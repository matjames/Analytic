# StatGate Field Operations SOP

## Purpose

Use this procedure to register, update, review, and deactivate field survey stations while maintaining accurate coverage and territorial records.

## Standard workflow

1. Confirm the station location using region, district, municipality/DLG, and subcounty.
2. Record the station tier, operating model, managing organisation, and deployment capacity.
3. Submit the request for review before publishing it to the registry.
4. Review approved changes regularly and deactivate stations that are no longer operational.

## Data quality

Use a clear station name, a valid location, and a current contact point. Do not store personal information that is not needed for operational coordination.
