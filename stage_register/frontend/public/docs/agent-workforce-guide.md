# Agent Workforce Guide

## Using the registry

The registry links field survey stations with the territories where enumerators and field teams operate. Use the geographic filters to understand active coverage by region, district, municipality/DLG, and subcounty.

## Operational roles

- Field coordinators maintain station information and submit change requests.
- Reviewers approve or return requests for correction.
- Registry administrators manage station tiers, operating models, managing organisations, and published resources.
